# The Forest Adventure

Copyright (C) 2023 Alvar Eklind

## About

This is a text-based, turn-based story game where you explore a mysterious forest.  
The game currently includes:
- 4 different endings
- A save system
- Multiple character classes

Planned features include spells, a leveling system and shop system and possibly additional story.

## Installation

1. Create a folder on your computer
2. Open command prompt (or terminal) in the folder by right clicking
3. Run `git clone https://github.com/Hiphopnej/Textbased_game`

### Usage

Navigate into the project folder and run: `The Forest Adventure.py`

### Version Requirment

Python 3.11.4
